# RAN: New Generation — Web MMORPG Prototype

ต้นแบบเกม 3D มุมมองบุคคลที่ 3 กราฟิกอนิเมะ เล่นคนเดียวบนเว็บไซต์

## วิธีเปิด
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน `ran_new_generation` ไปยังโฮสต์แบบ Static Site (เช่น GitHub Pages, Netlify, Cloudflare Pages หรือ Render Static Site)
3. ตั้งค่า Publish/Root directory เป็นโฟลเดอร์ที่มี `index.html`
4. เปิด URL ผ่าน HTTPS

สามารถทดลองในเครื่องโดยใช้ Live Server หรือรัน `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

## การควบคุม
- WASD / ปุ่มลูกศร: เดิน
- คลิกพื้น: เดินไปยังตำแหน่ง
- คลิกมอนสเตอร์: เลือกเป้าหมาย
- Space หรือปุ่มโจมตี: โจมตี
- ปุ่มสกิลด้านล่าง: ใช้สกิล
- เมนูด้านซ้าย: อาชีพ, ร้านค้า, กระเป๋า, แผนที่

## ระบบที่มีในต้นแบบ
- ฉากเมือง 3D และแผนที่ทดลอง 4 โซน
- ตัวละครต้นแบบและตัวเลือก 5 อาชีพ / 2 เพศ
- มอนสเตอร์ปีศาจ, โจมตี, HP, EXP, เลเวล
- NPC และร้านค้าจำลอง, ซื้อยาและอาวุธ
- กระเป๋าไอเทม, ใช้ยา, เปลี่ยนแผนที่
- HUD, แถบ HP/MP, เควสเริ่มต้น

## ข้อจำกัดสำคัญ
นี่คือ **ต้นแบบเล่นคนเดียว (single-player prototype)** ยังไม่ใช่เกม MMORPG เต็มรูปแบบ: ยังไม่มีระบบเซิร์ฟเวอร์/บัญชีผู้เล่น, บันทึกข้อมูลถาวร, โมเดลตัวละครอนิเมะคุณภาพผลิตจริง, ระบบเควสเต็ม, AI บอส, ระบบดรอปไอเทมจริง, เสียง, แอนิเมชัน rigged หรือระบบป้องกันโกง ต้องพัฒนาต่อก่อนเปิดให้บริการจริง

เกมใช้ Three.js จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตตอนโหลดเกม และควรตรวจสอบนโยบายโฮสต์/HTTPS ก่อนเผยแพร่
